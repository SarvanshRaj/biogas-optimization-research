# Biogas Optimization Research

A project focused on optimizing biogas yield through predictive modeling and controlled fermentation.

## Project Scope
The goal is to evaluate the biogas yield of various organic substrates (carbohydrates, proteins, fats) and optimize the mixture ratios using a 2-stage fermentation system utilizing *Aspergillus oryzae*.

## Technical Architecture
1. **Data Acquisition:** Sensor-integrated monitoring of temperature, pH, and gas volume.
2. **Preprocessing:** Feature engineering of substrate mixture ratios and environmental variables.
3. **Modeling:** A Supervised Learning framework (Regression) to predict peak methane output based on input substrate composition.
4. **Hardware:** Prototype anaerobic digester with automated data logging.

## Roadmap
- [ ] Finalize sensor array calibration (pH/Methane sensors).
- [ ] Collect baseline fermentation data for single-substrate mixtures.
- [ ] Train initial predictive model on experimental data points.
- [ ] Validate model accuracy against 2-stage fermentation results.
